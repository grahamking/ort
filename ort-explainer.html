03 / fewer moving parts

Lean by construction

The binary carries its own narrow platform layer.

⌁

no_std release

Uses alloc without the standard library. Direct Linux syscalls in inline assembly keep the dependency graph flat.

▰

Static, stripped ELF

Release flags use LTO, one codegen unit, symbol stripping, static relocation, and a minimal linker setup.

▱

Hand-rolled primitives

Assembly supplies memcpy, memset, strlen, memcmp, and friends normally provided by libc.

↯

Native machine code

-Ctarget-cpu=native lets LLVM tune the release for the x86_64 CPU it runs on.

04 / memory without drama

Arena, not churn

Short-lived CLI processes do not need a general-purpose lifetime strategy.

ReserveAnonymous memory arrives in 1 MiB chunks via mmap.
BumpAllocations advance an offset, aligned to 16 bytes—no per-object syscall.
ReuseOld sections stay alive until exit; deallocation is intentionally a no-op.
PredictBuffers use with_capacity; a debug feature can catch accidental reallocations.

06 / remove avoidable waiting

Network details count

The model and provider still dominate end-to-end latency. ort trims the local overhead around them.

DNSSet dns in config to skip resolver work; otherwise ort has a tiny A-record resolver.
ConnectNon-blocking connect plus poll timeout avoids an unbounded SYN wait.
SocketTCP Fast Open is enabled before connecting, where the network supports it.
ϟ

Fast is a whole-stack property. A minimal executable, fewer allocations, direct syscalls, a focused TLS client, and immediate streaming cannot make a remote model think faster—but they make sure ort is ready when the first byte arrives.
