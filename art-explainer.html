The agent, in one page.

art turns a user prompt into a streaming, tool-using coding loop. It keeps the conversation in memory, sends each turn to OpenRouter, executes approved local tools, then feeds their results back to the model.

The inner loop: think → act → continue

A tool call is not the end of a turn. Its result becomes the next model input.

run_single()
01 / SEND

Clone the conversation and tool catalog into ActivePrompt. Build a streaming chat-completions request.

02 / RECEIVE

Consume events: reasoning, text, annotations, and streamed tool-call fragments. Assemble calls by index.

03 / EXECUTE

Parse each function name and JSON arguments. Display it, run the local tool, and capture success or error JSON.

04 / FEED BACK

Append one assistant message containing the calls, then one tool message per result. Repeat if calls existed.

Exit condition: when the assistant emits content without tool calls, run_single returns false; aggregate stats are printed and the outer loop waits for another prompt.
